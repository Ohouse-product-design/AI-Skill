# ingest — 새 소스를 위키에 녹인다

> 🔴 **요약이 아니라 통합이다.** 소스를 읽고 요약 페이지 하나를 새로 만드는 것으로 끝나면 RAG 와 다를 게 없다.
> 목표는 **기존 페이지들이 이 소스를 반영해 달라지는 것**이다.

## 절차

```
① 소스를 읽는다
② 🔴 델타를 말한다 — 요약이 아니라 "기존과 무엇이 다른가"
③ 영향 페이지를 특정한다 (index.md 로)
④ 갱신한다 — 값은 복사하지 않고 링크한다
⑤ index.md 갱신 · log.md append
```

### ② 델타 4종 — 이 중 하나로 분류해서 말한다

| 델타 | 뜻 | 처리 |
|---|---|---|
| **신규** | 위키에 없던 사실 | 해당 엔티티/개념 페이지에 추가. 없으면 페이지 신설 |
| **충돌** | 기존 값과 다르다 | 🔴 **덮어쓰지 않는다.** 둘 다 남기고 어느 쪽이 정본인지 판정 → 판정 불가면 미결 |
| **정본 밖** | 정본에 없는데 실제로 운영되는 것 | 🔴 **역방향 드리프트**(린트 L7). 정본 등재 안건으로 올린다 |
| **무변화** | 이미 반영돼 있다 | log 에 한 줄만. 페이지는 건드리지 않는다 |

> "요약했습니다" 로 끝내지 않는다. **무변화도 결과다** — 그렇게 적는다.

## 소스 타입별

| 타입 | 읽는 법 | 주로 갱신되는 페이지 |
|---|---|---|
| **Notion 정본** | `notion-fetch` · 루트 → IA i~vi. 🔴 프로젝트 규칙은 **해당 1개만** | `references/` 캐시 전반 · `notion-map.md` |
| **지면 DB 행** | 행 페이지 개별 fetch | `page-catalog.md` · 해당 `macrostructures/*.md` |
| **ODS 패키지** | MCP 우선 → `unavailable` 이면 오프라인 `node_modules` 폴백 (`components.md` § 사다리) | `color.md` · `typography.md` · `components/*.md` |
| **스토리북** | 스토리 path 로 실물 확인 | `components/*.md` · 중복 3건 |
| **prod 실측** | `gate-static.js <url> --derive --scale` | `layout-and-space.md` · `responsive.md` |
| **세션 산출물** | `preview/*/CHANGES.md` | `index.md` § 워크스페이스 산출물 · `log.md` |

### ODS 패키지를 읽을 때 — 버전 드리프트를 먼저 본다

MCP 검증 카탈로그와 오프라인 설치본의 버전이 다르다. **어느 쪽을 읽었는지 반드시 표기한다.**

```
MCP 검증        design-system 13.2.4 · tokens 4.0.0 · icons 3.24.1
오프라인 설치본  design-system 11.5.1 · tokens 3.12.0 · icons 3.24.1  (로컬 프로토타입 워크스페이스의 `node_modules`)
```

🔴 **빈 카탈로그의 "없다" 를 근거로 쓰지 않는다.** `list_components` 가 `count:0 · unavailable` 이면
`check_component_name` 의 `isOds:false` 도 무의미하다 — 무엇을 물어도 "없다" 가 나온다.
(미결 **O-4** 가 정확히 이 함정에서 나왔다.)

## ④ 갱신 규칙

- **값은 한 곳.** 이미 다른 페이지에 있는 수치는 **링크**한다. 옮겨 적으면 그 순간 두 벌이 된다
- 미러를 둘 때는 **"정본은 여기"** 를 표기한다
- 새 페이지를 만들 때는 `conventions.md` § 페이지 규약을 따른다
- 🔴 **한 소스가 10~15 페이지를 건드릴 수 있다.** 전부 건드리고 나서 index 를 갱신한다

## 배치 ingest

여러 소스를 한 번에 넣을 수 있지만 **감독이 줄어든다**. 배치로 갈 때는:

- 델타가 **충돌**인 것만 사람에게 보고한다
- 배치 후 반드시 `lint` 를 돌린다 — 배치는 모순을 만드는 가장 흔한 경로다
