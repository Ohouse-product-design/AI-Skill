# query — 위키로 답하고, 좋은 답은 되돌린다

> 🔴 **답이 채팅 히스토리에 남고 끝나면 위키는 자라지 않는다.**
> 탐색도 소스처럼 축적돼야 한다.

## 절차

```
① index.md → 관련 페이지 특정 → 그 파일만 읽는다
② 인용과 함께 답한다 — `파일:줄` 또는 Notion URL
③ 적재 판정
④ log.md append
```

## ① 페이지 특정 — 질문 유형별 진입점

| 질문 | 먼저 여는 것 |
|---|---|
| "이 지면은 어떤 pattern 인가" | `page-catalog.md` → `macrostructures/*.md` **1개** |
| "이 블록에 뭘 써야 하나" | `components.md` → `components/r-*.md` **1개** |
| "이 폭에서 어떻게 변해야 하나" | `responsive.md` (절차) → `layout-and-space.md` (수치) |
| "이 색·글자 써도 되나" | `color.md` · `typography.md` |
| "이거 왜 이렇게 정해졌나" | `open-decisions.md` § 확정 |
| "지금 뭐가 열려 있나" | `wiki/synthesis.md` § 열린 것 |
| "최근에 무슨 일이 있었나" | `wiki/log.md` |

🔴 **6개·12개를 다 읽지 않는다.** 인덱스에서 이름을 고르고 그 파일 1개만.

## ② 인용 규율

- 수치를 말할 때는 **어디서 왔는지** 같이 말한다 — `layout-and-space.md:34` 또는 Notion URL
- 🔴 **캐시에서 읽었으면 캐시라고 말한다.** 정본은 Notion 이고 캐시는 뒤처져 있을 수 있다
- 실측이면 **언제·무엇으로 쟀는지** 말한다 (`gate-static.js` 5폭 · tokens 3.12.0 등)
- 모르면 모른다고 한다. 🔴 **열린 결정을 진행을 위해 임의로 닫지 않는다**

## ③ 적재 판정 — 남길 것과 버릴 것

**남긴다:**

| 조건 | 어디에 |
|---|---|
| 소스 간 **모순**을 찾았다 | `wiki/lint.md` § 모순 + 해당 페이지에 표기 |
| 정본에 없던 **실측값**을 얻었다 | 해당 개념 페이지 + `wiki/log.md` |
| 다시 쓸 **비교표**를 만들었다 | 새 페이지 (`wiki/` 또는 `references/`) + `index.md` |
| **결정 대기** 항목이 생겼다 | `wiki/synthesis.md` § 열린 것 + `open-decisions.md` 등재 안건 |
| 여러 페이지를 잇는 **연결**을 발견했다 | 양쪽 페이지에 상호 링크 |

**버린다** — 이미 위키에 있는 것의 재진술 · 한 번 쓰고 말 계산 · 소스 없는 추측.

> **판정 기준 한 줄** — *"3개월 뒤에 누가 이걸 다시 물을까?"* 그렇다면 남긴다.

## 산출 형태

질문에 따라 달라진다. 마크다운 페이지가 기본이고, 그 외:

| 형태 | 언제 | 주의 |
|---|---|---|
| 비교표 | 두 개 이상을 나란히 놓을 때 | 값은 링크로, 표에 복사하지 않는다 |
| HTML 프로토타입 | 규격을 **보여줘야** 할 때 | 🔴 이건 `lifeservice-uxui` 영역이다. 게이트를 태운다 |
| 차트 | 시계열·분포 | 데이터 출처 명시 |

🔴 **비교표를 만들 때가 값 중복이 가장 잘 생기는 순간이다.** 표 안의 수치는 원본 페이지를 링크한다.
