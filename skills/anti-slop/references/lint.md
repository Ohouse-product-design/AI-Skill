# lint — 위키 건강검진 7종

> 🔴 **린트는 진단이다. 고치는 것은 분류에 따라 다르다** — AUTO 만 즉시 수정하고, PROPOSE·HUMAN 은 미결 대장으로 간다.
> 결과는 시점과 함께 `wiki/lint.md` 에 남긴다.

## 실행

```bash
node skills/anti-slop/scripts/wiki-lint.js skills/anti-slop --json skills/anti-slop/wiki/qa-lint.json
```

`--all` 스캔 범위를 `preview/` · `skills/` 까지 넓힌다 · `--canon <file>` 기본 `wiki/canon.json`.
종료 코드 `0` 차단 없음 / `1` 🔴 차단 / `2` 실행 오류.

## 점검 7종

| # | 무엇 | 자동 | 분류 | 이 도메인에서의 형태 |
|---|---|---|---|---|
| **L1** | **모순** — 같은 값이 두 페이지에서 다르다 | ✅ canon 선언분만 | 💬 | UICG 재료 수가 13 / 19 / 21 세 벌 |
| **L2** | **stale** — 캐시 날짜 < 실제 최종 편집 | ✅ | 🔧 | 헤더는 `2026-08-10` 인데 본문에 08-13 결정이 있다 |
| **L3** | **고아** — 인바운드 링크 0 | ✅ | 💬 | 어디서도 링크되지 않는 페이지 |
| **L4** | **누락 개념** — 여러 곳에서 언급되는데 자기 페이지가 없다 | ❌ | 💬 | `archetype` · `로깅 계약(C1)` |
| **L5** | **끊긴 상호참조** | ✅ | 🔧 | 링크 대상 파일 부재 |
| **L6** | **데이터 갭** — 조회·실측으로 채울 수 있는 "판정 불가" | ❌ | 🙋 | O-1 progressbar 분모 · O-4 `Card` 판정 |
| **L7** | **역방향 드리프트** — 🔴 **캐시가 정본보다 앞서 있다** | ❌ | 🙋 | Notion §vi 트리에 없는 `work-scopes.md` · `hero-kv-prompt.md` |
| + | **L8** 인덱스 커버리지 · **L9** 중복 사본 · **LOG** 표기 | ✅ | 🔧 | |

🔴 **L4 · L6 · L7 은 스크립트가 판정하지 않는다.** 자동 결과만 보고 "건강함" 이라고 쓰지 않는다.

## L2 가 mtime 을 보지 않는 이유

처음엔 파일 수정일(mtime)로도 stale 을 잡았다. **틀린 설계였다** —
헤더 날짜를 고치는 행위 자체가 mtime 을 바꾸므로, 고친 파일이 **다음 회차에 다시 결함으로 잡힌다**.
`gate-loop` 가 말하는 🔁 **무효 수정**(진단이 틀렸다)이고, 영원히 수렴하지 않는다.

그래서 L2 는 **본문이 스스로 증언하는 날짜만** 본다 — 헤더가 `2026-08-10` 인데 본문에 `2026-08-13` 결정이
적혀 있으면 그건 내용 자체가 모순이므로 무효 수정이 아니다.

🔴 **대신 "언제 마지막으로 sync 했는가" 는 이 스크립트가 답할 수 없다.** 그건 git 이 답할 문제이고,
이 워크스페이스는 아직 저장소가 아니다 (`conventions.md` § 아직 없는 것).

## L1 이 canon 선언분만 보는 이유

일반 정규식으로 `<명사> N종` 을 전부 긁으면 **오탐이 30건 넘게 나온다**(실측).
`CTA 최대 2개`(규칙)와 `CTA 3개 → 어느 것을 지울지`(예시)는 같은 표현이지만 모순이 아니다.

그래서 L1 은 `wiki/canon.json` 에 **선언된 것만** 본다. 선언이 없으면 **미실행**으로 표기된다 — 통과가 아니다.

```json
[
  { "term": "화면 패턴", "unit": "종", "expect": 6 },
  { "term": "재료", "unit": "종", "expect": null,
    "scope": ["imagery-kit.md", "r-uicg.md", "work-scopes.md"] }
]
```

- `expect` — 정본 값. `null` 이면 "여러 벌이면 안 되지만 정본은 미확정" 이라는 뜻이고, 값이 갈리면 🔴
- `scope` — 셀 파일을 좁힌다. **동음이의를 거르는 유일한 수단**이다 (`재료 5종 상한`은 W4 그래픽 재료로 별건)
- `lint.md` · `log.md` 는 자동 제외된다 — 위키의 **주장**이 아니라 위키에 대한 **보고**다

## 처방 — 분류대로

| 분류 | 무엇을 한다 |
|---|---|
| 🔧 **AUTO** | 즉시 고치고 재측정. 날짜 갱신 · 링크 경로 · index 등재 |
| 💬 **PROPOSE** | 🔴 **고르지 않는다.** 선택지와 되돌리는 비용을 적어 미결 대장에 올린다 |
| 🙋 **HUMAN** | 미결 대장에만. **정본(Notion) 편집은 대리하지 않는다** |

## 리포트 형식 — `wiki/lint.md`

```markdown
> N차 전수 YYYY-MM-DD. 대상 <범위>.
> 🔴 이 문서는 진단이다. 고치지 않았다.

| # | 점검 | 결과 |
...
## N. 🔴 <제목>
<무엇이 어긋났나 — 값과 위치>
**해석** — 왜 이렇게 됐는가
**처방** — 무엇을 하면 닫히는가 · 분류

## 다음 린트에서 볼 것
- [ ] ...
```

🔴 **"다음 린트에서 볼 것" 을 반드시 남긴다.** 린트는 1회성 감사가 아니라 **누적**이다.
