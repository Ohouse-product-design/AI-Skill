# conventions — 페이지 규약 · 값 중복 판정 · log 표기

## 페이지 규약

| | |
|---|---|
| **파일명** | 엔티티는 역할 ID 소문자(`r-grid.md`) · 패턴은 번호+이름(`01-landingpage.md`) · 개념은 축 이름(`color.md`) |
| **첫 줄** | `# <제목>` |
| **두 번째 블록** | `> 출처: <정본 URL> · 캐시 fetch <YYYY-MM-DD>` — 캐시 페이지는 **필수** |
| **링크** | 상대경로 마크다운 링크. Obsidian 은 워크스페이스 루트를 vault 로 연다 |
| **길이** | 인덱스는 슬림하게. 상세는 개별 파일로 내린다 — **인덱스가 길어지면 2단 구조가 무너진다** |

## 🔴 값 중복 금지 — 이 위키가 가장 자주 깨지는 지점

> *"값의 중복은 지우고 링크의 중복은 둔다"* — `references/notion-map.md`

**판정** — 수치·목록·이름을 적으려 할 때:

```
이 값이 이미 다른 페이지에 있는가?
  ├─ NO  → 여기가 정본이다. 적는다
  └─ YES → 🔴 적지 않는다. 링크한다
            └─ 조회 편의상 꼭 보여야 하면 → 적되 "정본은 <링크>" 를 함께 표기
```

**실제로 이렇게 깨졌다** — UICG 재료 수를 결정 H2-2 가 21로 올렸는데, `imagery-kit.md` 는 19까지만,
`r-uicg.md` · `work-scopes.md` 는 확장 전 13에 머물렀다. **한 번의 확장이 3단계로 반쯤 전파된 상태**다.
수치를 한 곳에만 뒀다면 생기지 않았다.

## log 표기

```
## [YYYY-MM-DD] <verb> | <제목>
```

`verb` ∈ `ingest` · `query` · `lint` · `build` · `sync`. 최신이 위. **append-only** — 과거 항목을 고치지 않는다.

```bash
grep "^## \[" wiki/log.md | tail -5      # 최근 5건
grep "^## \[" wiki/log.md | grep lint    # 린트 이력만
```

본문은 2~4줄. **무엇이 달라졌는지**를 적는다 — "읽었다" 가 아니라 "무엇이 바뀌었다".

## severity · 분류 표기

| 표기 | 뜻 |
|---|---|
| 🔴 | 차단 — 이대로 진행하면 안 된다 |
| 🟡 | 지적 — 진행 가능하나 재작업 위험 |
| 🟢 | 백로그 |
| 🔧 AUTO · 💬 PROPOSE · 🙋 HUMAN | 누가 닫을 수 있는가 |

## 아직 없는 것 — 정직하게 적어둔다

| | 상태 |
|---|---|
| **git** | ❌ 워크스페이스가 저장소가 아니다. 45페이지가 버전 이력 없이 직접 편집된다 (린트 L2 가 그래서 생겼다) |
| **검색** | 현재 `index.md` 로 충분. 더 커지면 [qmd](https://github.com/tobi/qmd) 같은 로컬 하이브리드 검색 |
| **프론트매터** | ❌ Dataview 쿼리를 쓰려면 YAML 프론트매터가 필요하다 |
| **역링크** | ❌ 인바운드는 린트가 세지만 페이지에 표시되지 않는다 (Obsidian 은 자체 지원) |
